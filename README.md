### 📂 Repository Contents
> **Note on Source Code:** This repository *does not* contain application source code. This is strictly a **Cloud Infrastructure and Operations** project. The objective was to architect, provision, secure, and monitor a highly available hosting environment, not to develop software. The frontend was dynamically injected directly on the server via CLI to validate the Apache configuration.

Because the value of this project lies in the cloud architecture, this repository contains the following artifacts as proof of deployment:

1. **Comprehensive Documentation:** A detailed, step-by-step architectural report outlining the server setup, firewall configurations, deployment process, and troubleshooting methodologies.
2. **Video Demonstration:** A live walkthrough proving the functioning infrastructure, including MobaXterm remote access, the live web application, and active CloudWatch performance metrics.
